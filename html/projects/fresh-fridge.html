Fresh Fridge

Voor dit project heb ik samen met mijn team een slimme koelkastapplicatie ontwikkeld met behulp van Java, Spring Boot, React en TypeScript.

Het doel van FreshFridge was om gebruikers te helpen bij het beheren van producten in hun koelkast en voedselverspilling te verminderen. Gebruikers konden een eigen koelkast aanmaken en producten toevoegen door bijvoorbeeld een barcode te scannen. Hiervoor maakten we gebruik van de OpenFoodFacts API , zodat productinformatie automatisch kon worden opgehaald.

Ik heb onder andere gewerkt aan de backend-logica voor het beheren van koelkasten en producten, het toevoegen en verwijderen van producten en het aanpassen van aantallen. Daarnaast hebben we een notificatiesysteem ontwikkeld dat gebruikers waarschuwt wanneer producten bijna over de houdbaarheidsdatum zijn. De producten kregen hierbij verschillende kleuren op basis van hun versheid, zodat de gebruiker in één oogopslag kon zien welke producten als eerste gebruikt moesten worden.

Het doel van de applicatie was om gebruikers een duidelijk overzicht te geven van wat er in hun koelkast ligt, hoe lang producten nog houdbaar zijn en welke producten binnenkort gebruikt moeten worden. Hierdoor kan de gebruiker boodschappen en maaltijden beter plannen en wordt de kans op voedselverspilling kleiner.

Technieken:
Java • Spring Boot • React • TypeScript • MySQL • REST API
