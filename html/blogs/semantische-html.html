Wat ik leerde over semantische HTML

16 september 2026

Wat is semantische HTML?

Semantische HTML betekent dat je HTML-elementen gebruikt die duidelijk aangeven wat de functie en inhoud van een onderdeel op de pagina is. Zo gebruik je bijvoorbeeld een nav-element voor de navigatie, een main-element voor de belangrijkste inhoud van de pagina en een article-element voor een zelfstandig stuk inhoud. Hierdoor krijgt de website een duidelijkere structuur en is de code makkelijker te begrijpen en te onderhouden.

Waarom is dit belangrijk?

Veel beginnende programmeurs gebruiken vaak div-elementen om verschillende onderdelen van een website te groeperen. Tijdens de lessen en het maken van mijn portfolio heb ik geleerd dat je beter kunt kijken of er een semantisch elemnt bestaat dat duidelijker aangeeft wat de functie van een onderdeel is.

Wat heb ik geleerd?

In plaats van voor alles div-elementen te gebruiken, probeer ik nu eerst te kijken naar de functie en de opbouw van een onderdeel. Daarna bepaal ik welke layout ik wil maken en kijk ik of daar een passend semantisch HTML-element voor bestaat. Op deze manier wordt mijn code duidelijker opgebouwd en is beter te begrijpen waarvoor elk onderdeel van de pagina bedoeld is.

Hoe pas ik dit toe?

In mijn portfolio gebruik ik verschillende semantische HTML-elementen, zoals header, nav, main, section, article en footer. Daarnaast gebruik ik ook elementen zoals h1, h2, p, a en img om de inhoud van mijn pagina's duidelijk op te bouwen. Door deze elementen op de juiste plek te gebruiken, krijgt mijn website een logische structuur en wordt het voor andere ontwikkelaars ook makkelijker om mijn code te begrijpen.
